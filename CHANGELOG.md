# Changelog

All notable changes to Dart Room will be documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Conditional static export for embedding at `/project-apps/dart-room`.
- Canonical share routing through `/projects/dart-room/play` and `noindex` metadata for the raw artifact.
- Static artifact contract tests and continuous integration coverage.
- Public contribution, conduct, security, architecture, and repository-maintenance documentation.

## [1.0.0] - 2026-07-30

### Added

- Browser-based 3D dartboard with pointer and keyboard-friendly throwing controls.
- Count Up, 301, and Cricket modes.
- Solo, local two-player, and CPU play with three difficulty levels.
- Responsive presentation, accessibility checks, sound controls, sharing, and a local Count Up personal best.
- Deterministic scoring tests and cross-browser end-to-end coverage.
